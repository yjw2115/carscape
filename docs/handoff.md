# Carscape 작업 인수인계 — 지금까지의 결정 요약

## 1. 공모전
- 현대차 Pleos 차량용 앱 공모전. 접수 마감 11/15, 1차 서류 결과 11/23, 최종 PT 12/3~4. 개발 산출물은 선택 제출.
- 심사 기준: 차량특화성(모바일과 다른 차량 가치) · 창의성(Pain Point 정의) · 기술 활용성(Pleos SDK를 핵심 기능에 사용) · 사업성(타깃, MAU·리텐션, 확대 계획).

## 2. 아이디어: 차량 방탈출
- 차 자체가 방탈출 방. 퍼즐 정답을 차량 상태 읽기로 판정.
- 사업성: 주기적 신규 시나리오 출시(시즌제), 시나리오별 배지 수집, 구독/시즌패스, 지자체·브랜드 협업 시나리오, 시승센터 마케팅(차 기능 학습 효과).
- 공식 SDK 현황(문서 기준): Vehicle, NaviHelper, STT, TTS, FusedLocation. STT/TTS/차량 제어는 준비 중 → 음성은 미리 녹음한 파일 재생, 음성 퍼즐은 로드맵.
- 실내 카메라 API 없음 → 동작 인식 대신 착석 센서·안전벨트·핸들·페달 등으로 "몸으로 하는 퍼즐".

## 3. 앱 구조와 화면 (design/ 참고)
- 진입 · 차량 점검: E1 모드 선택, E2 점검 안내, E3 점검 진행, E4 감지 실패·재시도, E5 점검 결과
- 튜토리얼 "얼어붙은 밤": T0 소개 ~ T7 대피소 도착
- 본편 시안: 홈, 안전 브리핑, 플레이, 주행 감지 일시정지, 탈출 결과 (본편 시나리오는 아직 확정 아님)
- 공통 UI: 스플래시, 시나리오 상세, 나레이션 노트 창, 힌트 창(3단계, 열 때마다 기록 +1분), 정답 연출, 실패 결과(막힌 곳부터 다시), 배지 획득, 배지판
- 화면 규칙은 CLAUDE.md의 "반드시 지킬 설계 규칙" 참고.

## 4. 튜토리얼 "얼어붙은 밤" (가족 협동, 초등학생부터, 약 15분, 실패 없음)
설정: 기상이변으로 기온이 급격히 떨어졌고 차량이 고장 났다. 완전히 얼어붙기 전에 30분 안에 고치고 탈출하라!
| 단계 | 상황/나레이션 | 판정 장치 |
|---|---|---|
| T1 정전 | "다들 괜찮아? 어두워서 아무것도 안 보여…" (앱 화면 암전) | - |
| T2 배터리 | 트렁크 배터리 → 뒷좌석 왼쪽 → 뒷좌석 오른쪽 → 조수석 → 운전석 순서 | 시트 열선 4석(순서) |
| T3 글로브박스 | "수리 도구… 글로브박스에!" "얼어 있는 건가?" | 조수석 히터 → 글로브박스(미지원 차량은 히터까지만) |
| T4 창문 회로 | "공기가 희박해… 창문 좀" "창문도 먹통이구먼" | 창문 4개 위치로 러시아워식 퍼즐(0~50%만) |
| T5 눈 치우기 | "대피소가… 눈이 쌓여 안 보여요" | 김서림 제거 + 와이퍼 단계 1→3→1 |
| T6 출발 준비 | "모두 살아남는 거야!" | 착석한 모든 자리 안전벨트 + 브레이크 3초 |
| T7 결과 | 대피소 도착, 기본 훈련 배지, 이 차에서 확인된 장치 | - |
- 나레이션이 곧 힌트. 놓치면 노트 버튼으로 다시 듣기 + 자막. 일정 시간 진행 없으면 자동 힌트.

## 5. 본편 시나리오 (미확정)
- 폭우·침수 테마 "시간당 120mm"로 가닥, 세계관/스토리는 아직 논의 중(혼자·미스터리 스릴러 방향 검토, 이입 문제로 재검토 예정).
- 퍼즐은 실제 생존 행동 순서와 무관한 순수 방탈출. 실제 대처법은 시작 전 안전 브리핑에서만 다룬다.
- 확장 시나리오 후보: 4계절 "고장 난 하늘".

## 6. 차량 점검 (담당 기능) — CLAUDE.md 상세 참고
- 자동 점검(조용히 전체) → 지원 장치 중 직접 점검 5개(사용 2~3 + 미끼 2~3, 다음 항목 숨김) → 실패 3회 시 화면 터치 대체 → 결과를 전역 상태로.

## 7. 배지
- 시나리오별 클리어 배지(모티프: 눈송이, 빗방울 등) + 테두리 등급(기본 / 은색=힌트 없이 / 금색=노힌트+제한 시간 절반) + 초판 리본(출시 2주 내, 배지 자체는 언제든 획득 가능).
- 배지판: 시즌 단위 칸, 미출시 칸은 "○월 공개" 실루엣, 시즌 완성 보상.

## 8. 읽을 수 있는 차량 요소 (Vehicle SDK 문서 기준, 실제 지원은 차종·에뮬레이터 확인 필요)
- 조용한 장치: 공조(설정 온도, 풍량, 풍향 조회, A/C, 오토, 내·외기 순환, 김서림 제거, 최대 제상·냉방, 실내 온도), 시트(위치·등받이·헤드레스트, 안전벨트 체결, 착석, 열선, 통풍), 핸들 각도·열선, 브레이크 페달, 글로브박스 잠금, 창문 잠금, 앰비언트 라이트, 주행 모드, 사이드미러 열선
- 티 나는 장치: 문 열림, 창문 위치, 와이퍼, 방향지시등, 전조등·안개등
- 데이터: 차대번호(VIN), 주행거리, 연료·배터리, 타이어 공기압, 경고등
