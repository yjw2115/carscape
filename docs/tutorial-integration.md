# 튜토리얼 작업 / 팀 연결 안내

문성훈 담당 범위. 브랜치: `feature/tutorial-frozen-night`. 기준 main: `d9aec04`.
사용자가 제시한 최신 시나리오가 기존 handoff/xlsx보다 우선한다.

## 이번 구현

테마 선택 후 소개 → 앱 화면 암전 및 대사 → 실내등 4자리 순서 → 조수석 히터·글로브박스 → 아무 창문 버튼 → 네 좌석 회로 퍼즐 → 와이퍼 → 전 좌석 안전벨트·화면 악셀 → 대피소 도착·결과.

- 시트 열선/브레이크 3초/와이퍼 1→3→1/김서림 제거는 이번 시나리오에 넣지 않았다.
- 실내등 순서: 뒷좌석 왼쪽 → 뒷좌석 오른쪽 → 조수석 → 운전석. 오답은 게임의 연결 표시만 초기화하며 실제 차량 불을 끄지 않는다.
- 글로브박스 열림 감지 미지원이면 히터 입력만으로 통과한다. 잠금 제어 없음.
- 창문 첫 버튼은 고장 대사와 회로를 여는 트리거이며 회로 이동에 재사용하지 않는다.
- 네 색의 선을 위아래로 이동해 입구부터 출구까지 연결한다. 각 자리는 서로 다른 입·출구 높이를 가지며 네 자리 조작이 모두 필요하다. 열림 0~50%, 10% 단위, 작은 센서 흔들림은 무시한다.
- 노트는 방문한 챕터의 대사를 보관한다. 열면 최근 챕터를 다시 읽고 대사를 눌러 개별 재생한다. 횟수 제한/기록 가산 없음.
- 힌트는 단계별 3개, 확인하고 열 때만 +1회, 최종 기록에 1분 가산. 45초 무진행이면 무료 노트 안내.
- 시간 초과 실패 없음. 실제 플레이 시간/힌트 수/가산 최종 기록을 표시한다.
- P단 이탈/연결 끊김/백그라운드/일시정지/노트·힌트 창에서는 입력과 타이머가 멈춘다.
- 음성은 OS/브라우저의 한국어 TTS. Pleos TTS SDK나 녹음 파일은 사용하지 않는다. 미지원 시 자막과 읽기 시간 후 자동 진행하며 수동 다음 버튼을 제공한다.

## 홈·진입 담당 연결

`lib/main.dart`는 체험용 최소 진입점이다. 기존 레포에 앱이 없어 Flutter 표준 Android/Web 실행 기반을 추가했다. 홈/모드 선택/차량 점검/공통 UI/본편은 구현하지 않았다.

```dart
Navigator.of(context).push(MaterialPageRoute(
  builder: (_) => TutorialScreen(
    onFinished: (result) {
      // 홈 담당이 결과 저장 및 복귀를 연결한다.
      Navigator.of(context).pop();
    },
  ),
));
```

기본 확인 크기는 960×600. 640×600/세로 화면에서는 스크롤 배치로 전환한다. Pleos가 제공하는 앱 영역에 맞춰 표시하며 계기판 영역을 내부에 다시 만들지 않는다. 테마는 tutorial 폴더 안에만 있다. `lib/core`, `lib/vehicle`, 팀 공용 장치 ID·점검 결과 규칙을 새로 정의하지 않았다.

## 실제 차량 연결 범위

**현재 실행본은 화면 조작 체험 모드다. Vehicle SDK/Kotlin 차량 브리지는 아직 구현하지 않았다.** 실제 실내등/글로브박스/악셀을 읽거나 전체 디스플레이·실내등을 끄는 앱이라고 설명하면 안 된다. 실제 차량 자동 제어는 없다.

차량 담당은 `TutorialInputSource.events`를 구현한 읽기 전용 스트림을 `TutorialScreen(inputSource: source, controller: controller)`로 전달할 수 있다. 소스가 있으면 체험 버튼을 숨긴다. 연결 모드는 처음에 P단/연결 확인을 기다리므로 `parking=1`, `connection=1` 신호가 모두 필요하다.

| 입력 | 값 | 자리 |
|---|---|---|
| `cabinLight` | 꺼짐 0 / 켜짐 1 | 네 자리 |
| `passengerHeater` | 꺼짐 0 / 따뜻한 바람 작동 1 | 없음 |
| `glovebox` | 닫힘 0 / 열림 1 | 없음 |
| `window` | 열림 비율 0~50 (닫힘 0) | 네 자리 |
| `wiper` | 꺼짐 0 / 작동 1 이상 | 없음 |
| `seatbelt` | 미연결 0 / 연결 1 | 네 자리 |
| `accelerator` | 해제 0 / 눌림 1 | 없음 |
| `parking` | P단 확인 1 / 그 외·불명 0 | 없음 |
| `connection` | 연결 정상 1 / 끊김 0 | 없음 |

이 표는 **튜토리얼 내부 계약**이며 Pleos SDK API/상수/지원 약속이 아니다. 실제 장치 ID/Capabilities/권한/구독/현재값은 차량 담당이 검증해 변환해야 한다. 안전벨트 단계 진입 시 현재 상태를 보내고 변화를 구독해야 한다. 악셀 API·네 자리 실내등 구분·기어 P 판정이 특히 확인 대상이다. 지원하지 않는 입력은 팀과 합의한 화면 대체 조작이 필요하다.

현재 외부 입력 연결은 통합 지점이며 실차 검증 완료 기능이 아니다. 힌트/노트 중 입력은 무시하므로 재개 시 상태를 다시 받아야 한다. 실제 창문은 게임에서 초기화할 수 없으므로 시작 기준점 정규화와 재시작 정책도 차량 담당과 결정해야 한다.
